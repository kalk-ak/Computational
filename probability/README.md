# Probability Notebooks

This directory contains a collection of Jupyter notebooks exploring various concepts in probability and statistics.

## Getting Started

To explore these notebooks, you'll need a Jupyter environment. If you don't have one set up, you can install it with pip:

`pip install notebook`

Then, you can launch the notebook server:

`jupyter notebook`

This will open a new tab in your web browser, allowing you to navigate to the directory containing these notebooks and open them.

## Notebooks

*   **Birthday_Problems.ipynb**: Explores the classic "birthday problem" in probability.
*   **intro-to-pandas-world-happiness.ipynb**: An introduction to the pandas library using the World Happiness Report dataset.
*   **Monty_Hall.ipynb**: A simulation and explanation of the Monty Hall problem.
*   **Naive_Bayes_Email_Classification.ipynb**: Demonstrates how to build a simple email spam classifier using Naive Bayes.
*   **Rideshare_Project_Week1.ipynb**: Appears to be the first week of a rideshare-related project.
