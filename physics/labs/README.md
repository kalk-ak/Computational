# Physics Labs Repository

This repository contains a collection of physics lab reports, data, and analysis notebooks. The labs are organized by topic into two main categories: Classical Mechanics and Electricity & Magnetism.

## Directory Structure

The repository is organized as follows:

- **`classical_mechanics/`**: This directory contains labs related to the principles of classical mechanics. Each subdirectory corresponds to a specific lab and contains the following:
    - `analysis.ipynb`: A Jupyter Notebook with the data analysis for the lab.
    - `readme.md`: A detailed report of the lab, including the introduction, methods, results, and conclusion.
    - `readme.pdf`: A PDF version of the lab report.
    - `data/`: A directory containing the raw data collected during the lab.
    - `images/`: A directory containing images and plots related to the lab.

- **`Electricity_and_Magnetism/`**: This directory contains labs related to the principles of electricity and magnetism. The structure of each lab subdirectory is the same as in the `classical_mechanics` directory.

- **`pdf2image-converter.py`**: A Python script used to convert PDF files into a series of images. This is useful for creating image previews of the lab reports.

- **`trash/`**: This directory contains old or unused files.

## Usage

To view a lab report, you can either open the `readme.md` file in a Markdown viewer or download the `readme.pdf` file. The data analysis for each lab can be found in the `analysis.ipynb` notebook, which can be opened using Jupyter Notebook or JupyterLab.
