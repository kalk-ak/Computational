# Classical Mechanics Laboratory

This repository contains a collection of laboratory experiments conducted for a classical mechanics course. Each directory corresponds to a specific lab, containing the data, analysis, and reports.

## Labs

Below is a list of the labs included in this repository:

- **Accelerometers**: An experiment involving the use of accelerometers.
- **ballistic-pendulum**: The classic ballistic pendulum experiment to determine the velocity of a projectile.
- **Data-Analysis-With-Python**: A primer on using Python for data analysis in the context of this lab course.
- **final_poster**: The final project for the course, presented as a poster.
- **inelastic-collisions**: An experiment to study inelastic collisions between objects.
- **motion-detector-analysis**: Analysis of motion using a motion detector.
- **noise-analysis**: An experiment to understand and analyze noise in measurements.
- **projectile-motion**: An experiment to study the motion of projectiles.
- **six-flags-data-analysis**: Data analysis of measurements taken at Six Flags.
- **the-small-angle-approximation**: An experiment to investigate the validity of the small-angle approximation for a pendulum.

## How to Use This Repository

Each lab is contained within its own directory. Inside each directory, you will typically find:

- `analysis.ipynb`: A Jupyter Notebook containing the data analysis for the lab.
- `data/`: A directory containing the raw and processed data from the experiment.
- `readme.md`: A detailed report of the lab.
- `images/`: A directory containing images and plots related to the lab.

To explore a lab, navigate to its directory and open the `analysis.ipynb` notebook. You will need a Jupyter environment to run the notebooks.
