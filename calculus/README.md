# Calculus and Optimization Notebooks

This directory contains a collection of IPython notebooks that explore various concepts in calculus, optimization, and machine learning. Each notebook is a hands-on lab that walks through the implementation of different algorithms and techniques.

## Notebooks

Here is a brief overview of each notebook in this directory:

- **`Classification_with_Perceptron.ipynb`**: This notebook introduces the concept of classification using a single perceptron neural network. It covers the structure of the neural network, the dataset, and the implementation of the model.

- **`Cost_Minimizing_Using_Gradient.ipynb`**: This notebook provides a practical example of solving a simple optimization problem for a function of one variable. It focuses on minimizing a cost function using the gradient descent method.

- **`differentiation_in_python.ipynb`**: This notebook explores different methods for computing derivatives in Python. It covers symbolic differentiation with `SymPy`, numerical differentiation with `NumPy`, and automatic differentiation with `JAX`.

- **`Linear_Regression_Using_Gradient_Descent.ipynb`**: This notebook demonstrates how to build a simple linear regression model to predict sales based on TV marketing expenses. It explores three different approaches: using `NumPy`, `Scikit-Learn`, and implementing gradient descent from scratch.

- **`Multivariate-Optimization-Using-Gradient-Descent.ipynb`**: This notebook extends the concept of gradient descent to optimize functions of two variables. It includes visualizations to help understand the optimization process.

- **`Neural_Network_With_2_Layers.ipynb`**: This notebook guides you through building and training a neural network with two layers. It covers the model's structure, forward propagation, and backward propagation for a classification problem.

- **`Optimization_Using_Gradient_Descent.ipynb`**: This notebook focuses on the implementation of the gradient descent method for functions with both single and multiple minima. It allows for experimentation with different parameters to understand the method's behavior.

- **`Optimization_Using_Newtons_Method.ipynb`**: This notebook implements Newton's method for optimizing functions in one and two variables. It also provides a comparison with the gradient descent method, highlighting the advantages and disadvantages of each.

These notebooks are designed to provide a practical and hands-on learning experience with the fundamental concepts of calculus and optimization in the context of machine learning.
